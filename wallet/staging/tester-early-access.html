What Stranded is

Tokens with no ETH can't move. Stranded finds them, swaps a slice for gas, and carries the rest home.

The product is GasRescueSwap. The holder signs once. An allowlisted relayer pays the gas. A slice of the token is swapped for native gas, and the remainder is sent to a wallet the holder chooses on the same chain. If any step fails, nothing moves.

Testnet only: Base Sepolia (84532) and Arb Sepolia, also called Arbitrum Sepolia (421614). Arb Sepolia is the primary testnet. Base Sepolia is secondary. There is no mainnet code path and no bridge in v1.

The wallet you actually test is the existing site at https://strandedtoken.trade. This draft is not that site. STRANDED is experimental, unaudited software provided as is, without warranties. It is a project of Steward of the King LLC.

What to try

  1. Open the wallet and pick Base Sepolia or Arb Sepolia. Mainnet is not offered.
  2. Connect an injected wallet. If it is on another network, switch to the testnet you picked. Use a wallet that does not hold mainnet funds.
  3. The wallet reads your token balance on that testnet. It does not invent a balance.
  4. Review every order field the wallet shows. Confirm the details. Only then does it ask you to sign. Cancel signs nothing.
  5. On Arb Sepolia, a connected wallet can request a tDEMO drip. tDEMO is the Stranded test demo token. The faucet cannot mint. It only sends tokens it already holds.

The rescue path is for a token holder who has no native ETH. The relayer pays that gas. If you still need testnet ETH for something else, use a public faucet below.
